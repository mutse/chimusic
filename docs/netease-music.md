# 网易云音乐

在“设置 → 网易云音乐”直接点击“扫码登录”，无需配置地址、部署服务或输入账号密码。

1. 点击“扫码登录”，使用网易云音乐 App 扫描二维码并确认。
2. 登录成功后点击“同步音乐”，导入喜欢的歌曲、创建及收藏的歌单。
3. 在音乐库顶部的“网易云歌单”中打开歌单，或从歌曲列表选择歌曲播放。

支持播放/暂停、进度、上一首/下一首、随机和循环。登录二维码过期可刷新；关闭设置会停止扫码轮询，但不会中断已开始的音乐同步。

同步为网易云到本机的单向手动同步，本机收藏修改不会上传。同步失败保留原有资料库；已从网易云移除但曾同步到本机的歌曲仍可手动清理。本地导入功能独立可用。

应用直接通过 HTTPS 请求网易云域名，二维码在本机生成。登录 Cookie 保存在系统安全存储，不写入播放记录导出、日志或 URL。退出登录清除本机凭证与网易云缓存，不修改网易云账号里的音乐。旧版服务地址配置会自动清理，旧版会话需要重新扫码。

播放地址在每次切歌时获取，不持久保存。不绕过会员或版权限制；遇到仅试听、无版权或账号无权限的歌曲会提示并停止，用户可切换下一首。目前混合/网易云队列在系统媒体通知中仅展示当前曲目。

## 开发验证

`lib/services/netease_client.dart` 封装固定域名的 EAPI HTTPS 请求及响应 Cookie。协议参考[社区项目原生接口实现](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)，应用不依赖运行该项目。此协议并非稳定的官方开放 SDK，上游调整时可能需要更新客户端。

```bash
flutter analyze
flutter test
dart run tool/netease_connection_check.dart
```

连接检查不需要账号，只申请未登录的二维码、验证等待扫码状态及公开歌曲接口；仅输出状态，不输出二维码 key、Cookie 或播放地址。真实账号的手机确认、私有歌单和付费歌曲播放仍需人工联调。
