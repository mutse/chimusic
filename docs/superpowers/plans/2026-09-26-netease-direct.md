# 网易云直接扫码登录实施计划

用户已明确要求：只需扫码登录，不配置兼容 API。继续保留既有歌曲同步和在线播放。

实现采用应用内 HTTPS 客户端，固定网易云官方域名，使用 EAPI 请求封装、响应 Cookie 与安全存储，二维码根据登录 key 本地生成。移除第三方服务配置和本机 HTTP 例外。不上报凭证，不引入公共代理，不绕过歌曲权限。
